How we work

Projects start in one of two ways. Both run through the same cycle—from first conversation to tested hardware and the documentation the next stage needs.

The requirement is clear

We scope the work, deliverables, programme and commercials before development begins.

The route isn't clear yet

A short first phase—weeks, not months—answers the technical question that matters most before the main programme commits.

  1. Learn the system

    We get to know the current technology, how it's used, what's going wrong, and what the next stage has to achieve.

  2. Set the next milestone

    We agree a milestone with defined deliverables and measures of success—a project you can steer, not an open-ended engagement.

  3. Develop and build

    Design, sourcing, assembly and integration—carried out by the same team that set the plan.

  4. Test and hand over

    Verification against the agreed measures, plus the design information and records your next stage needs.
