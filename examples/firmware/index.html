Scope

Work can include peripheral drivers, sensor acquisition, motion and actuator control, state machines, fault handling, wired and wireless communications, device configuration, and test utilities.

Developing firmware alongside the electronics and mechanical system makes it possible to resolve integration issues in the appropriate discipline, rather than compensating for every problem in software.
