Examples / Bikestow

Bikestow

Personal project · Automated post-operation machining centre

A machining centre with a front-mounted component buffer and automatic part detection, developed to run consecutive post-operation cycles without manual loading between parts.

Mechanical Electronics Firmware Production

Objective

Reduce the operator time required for repetitive post-operation machining. The machine needed to accept a batch of components, identify when each part reached the working position, complete the machining cycle, and continue to the next component.

System design

Components are loaded into a buffer at the front of the machine. The control system detects each component, positions it for machining, runs the cycle, and advances the next part. Mechanical, electronic, and firmware development were handled as one integrated system.

Mechanical design

The motion system uses a compact lead-screw gantry with machined aluminium brackets, designed around the available space and repeated cycling. The buffer, transfer path, workholding, and drive arrangement were developed together.

Electronics and firmware

A custom controller board and motor-drive electronics were assembled and brought up before integration with the mechanism. The firmware coordinates motion, limit sensing, component detection, cycle sequencing, and operator controls.
