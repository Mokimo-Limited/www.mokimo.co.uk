Examples / Bikestow

Bikestow

Automated post-op machining centre

A machining centre built to handle post-operation work on its own: components are loaded into a storage buffer at the front, detected automatically as they arrive at the machine, and processed one after another without an operator stood over it.

Mechanical Electronics Firmware Production

The problem

Post-operation machining is repetitive by nature, and the limiting factor usually isn't the cutting — it's the loading. A machine that needs a part placed in it by hand can only run for as long as someone is stood next to it, which makes small batches expensive in attention rather than in time.

How it works

Components are stacked into a buffer at the front of the machine. The controller detects each one as it arrives in position, runs the machining cycle, and moves on to the next, so the machine keeps working through the buffer without intervention or a restart between parts.

Mechanical design

The motion system is a compact gantry built from machined aluminium brackets on lead-screw drives, sized to fit an awkward footprint and to tolerate being cycled repeatedly rather than run once for a demonstration.

Electronics and firmware

A custom controller board drives the motors, hand-assembled and brought up on the bench before being integrated with the mechanism. The firmware ties the pieces together — coordinating motion, reading the detection and limit sensors, and handling the operator interface — so that the mechanical, electrical, and software sides behave as one machine rather than three subsystems sharing a frame.
